# 关于

> ⚠️ **左侧文档目录《关于》《功能介绍》是插件自带的只读示例：改动不会被保存**。关联文档仓库后不再出现，可以在设置查看。

---

## 这是什么

**DeepSeek Harness 的 Markdown 编辑器**：指定一个目录，用飞书级的编辑体验编辑你指定的 `.md` 文件。

- 编辑体验对齐**飞书**（悬浮格式栏、斜杠命令、即时转换）
- 目录部分对齐 **Obsidian 的最小集**（指定目录 + 文件树 + 打开编辑保存）
- 以 **CommonMark 0.31.2 ＋ GFM** 为标准：每一种写法都有例子，可在《功能介绍》里详细查看
- **磁盘上的文件永远是干净的 Markdown**——只接受能被 Markdown 无损表达的节点

---

## 安装

npm最新版本：[![npm](https://img.shields.io/npm/v/@yancy617/dsh-plugin-markdown)](https://www.npmjs.com/package/@yancy617/dsh-plugin-markdown)

```sh
dsh plugin --profile desktop add @yancy617/dsh-plugin-markdown
```

安装后**完全关闭并重新打开 DSH**，然后点左侧栏的 Markdown 图标。

## 卸载

```sh
dsh plugin --profile desktop remove @yancy617/dsh-plugin-markdown
```

DSH执行卸载即可，无任何残留。
