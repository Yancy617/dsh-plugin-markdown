# 功能介绍

> ⚠️ **左侧文档目录《关于》《功能介绍》是插件自带的只读示例：改动不会被保存**。关联文档仓库后不再出现，可以在设置查看。

## 一分钟上手

1. 左侧点「**选择笔记目录**」，选一个放 `.md` 文件的文件夹
2. 点文件打开，直接改
3. 不用找保存按钮：**停手两秒自动保存**；切到别的面板、关标签、窗口失焦，也会立刻存一次

切到别的面板再回来，打开的标签、没保存的改动、滚动位置都还在。

## 三个入口

| 想做什么 | 怎么进 |
| :--- | :--- |
| 改选中文字的样式 | 选中，头顶浮出**格式栏** |
| 插入标题 / 列表 / 表格 / 图片 | 在空行打 `/`，选一项 |
| 找某个功能 | `Ctrl + Shift + K` 打开命令面板 |

---

## 标题

一共六级，用格式栏或 `/` 菜单选即可。文件里就是行首几个 `#`：

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

## 文字样式

**粗体**、*斜体*、~~删除线~~、`行内代码`，还可以给文字挂一个[链接](https://me.eduaai.com)。

选中文字，格式栏点一下就好。文件里分别写成 `**粗体**`、`*斜体*`、`~~删除线~~`、`` `行内代码` ``。

## 列表

### 无序列表

- 无序列表：一行一条
- 回车自动续下一条
- 按 `Tab` 缩进一层，`Shift + Tab` 退回

### 有序列表

1. 有序列表会自动编号
2. 第二条
3. 第三条

### 任务列表

- [ ] 任务列表：点一下方框就勾上
- [x] 勾掉的样子

## 引用

> 引用适合放摘录、提醒、别人的话。
> 一行写不完可以接着写。

## 代码块

`/` 菜单选「代码块」，把代码贴进去就行；右上角有复制按钮。文件里开头那三个反引号后面写的语言名（比如 `js`）决定配色：

```js
function greet(name) {
  return `你好，${name}`
}

console.log(greet('世界'))
```

## 表格

`/` 菜单插入一张空表。鼠标停在**某一行或某一列**上，旁边会浮出手柄：插行、删行、插列、删列、改对齐都在里面。

| 操作 | 快捷键 | 说明 |
| :--- | :---: | ---: |
| 查找替换 | `Ctrl + F` | 当前这篇里找 |
| 命令面板 | `Ctrl + Shift + K` | 全部功能 |
| 关闭当前文档 | `Ctrl + Alt + W` | 先保存再关 |

这张表顺便演示了三种对齐：左、居中、右。

## 图片

![深蓝底上的白色 Markdown Image 字样](.img/示例图片.jpg)

图片用 `/` 菜单里的「图片」：挑电脑里的文件，或者直接粘贴截图，图片会存进仓库根的 `.img` 文件夹。

## 链接

网页地址单击就能打开，会在面板里新开一个网页标签，比如 <https://github.com/Yancy617/dsh-plugin-markdown>。

也可以给文字挂链接：[深度求索](https://www.deepseek.com/)。按住拖动选中链接文字不会打开链接；要改链接，选中后在格式栏里改。

## 复制粘贴

- 从网页、对话里复制的内容，粘进来会**直接变成格式**，不用手打记号
- 从这篇复制出去的，粘到 Word 里是排好版的文字，粘到代码编辑器里是标准 Markdown

## 文件与目录

- 左侧是文件夹树：**新建 / 重命名 / 删除**在行尾的 `⋯` 或右键菜单里
- **拖动一行**换顺序；**拖到文件夹上**就是移进去
- 「创建副本」按原样复制一篇，名字自动编号
- 可以同时开多个标签，各自保留没保存的改动；关标签前会先保存，存不上就不关

## 找到你想找的

- **文档目录**：右侧列出这篇的各级标题，点一下跳过去；分隔条可以拖宽，也能整体收起
- **查找替换**：`Ctrl + F`
- **字数**：工具条右侧一直显示「字符 · 词 · 行」
- **源码模式**：工具条「更多」里。看到的是文件原文，一字不差；它只读，改字仍在富文本里

## 快捷键

| 键                               | 作用            |
| ------------------------------- | ------------- |
| `Ctrl + S`                      | 立刻保存          |
| `Ctrl + Enter`                  | 在光标处，另起换一段    |
| `Shift + Enter`                 | 在光标处，另起换一行    |
| `Ctrl + F`                      | 查找替换          |
| `Ctrl + Shift + K`              | 命令面板          |
| `Ctrl + B` / `Ctrl + I`         | 粗体 / 斜体       |
| `Ctrl + Z` / `Ctrl + Shift + Z` | 撤销 / 重做       |
| `Ctrl + Alt + W`                | 关闭当前文档        |
| `F2`                            | 重命名左边鼠标停着的那一行 |

macOS 上把 `Ctrl` 换成 `Cmd`。

## 这些做不到

- **下划线**：标准 Markdown 里没有，不提供
- **HTML、脚注**：按原文保留，以可编辑的普通文本显示；不渲染 HTML / 脚注
- **表格**：表头那一行删不掉，至少要留一行一列
- **引用式图片**（`![图][名字]`）：能打开、能原样保存，但页面里不显示成图

## 小知识😀

- 笔记开头用 `---` 包起来的 frontmatter（标题、标签之类），**页面上不显示**，保存时原样保留
- 只改你动过的地方：没碰过的段落、列表、表格，保存时一个字节都不改
- 文末那个空段落不会写进文件
- 保存没成功（比如文件同时在别的程序里被改过）会用一条红色提示说明原因，不会悄悄丢字
