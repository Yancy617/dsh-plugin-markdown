| `tsconfig.scripts.json` | 探针那一份类型检查：`types: ['node']`、`include` 只收 `scripts/**/*.ts` / `.tsx`；不把 Node 全局漏进客户端 |
| `css-modules.ts` | 把 `*.module.css` 编译成内联注入模块：`scopeCss`（作用域与类名表）、`minifyCss`（保守压缩）、`injectionModule`（与官方预设同形的注入模块：`data-plugin` / `data-plugin-css` / 去重 / 默认导出类名表）、`hashOf` |
| `package.json` | 脚本入口（build / probe* / test / env:check）与对外契约（包名、exports、files、peerDependencies、dsh.bundle / dsh.client / dsh.compatibility）。不承诺类型：types / exports.*.types 不写，files 里没有 lib/types |
| `cordis.patch.yml` | bundle 层的一行 `insert`：id `markdown-editor`，`name` 是包名；平台靠它做 Node 解析。改包名要同一次改这里、`package.json#name`、profile 的 `dependencies` 键与 `dsh.profile.bundles` |
| `.git-hooks/pre-push` | 发布闸：`git push` 必须带 `DSH_PUSH_CONFIRMED=yes-by-human` 才放行（`core.hooksPath` 接线），否则拦下并打印远端还没有的提交与三条不许绕的规则。拦手滑，不拦有意绕过 |
