## 1 · 基础语法（CommonMark 0.31.2）

状态一栏四个词，含义固定：

- **建模** —— 有专属节点或状态，能在富文本里结构化编辑；
- **回放** —— 没建模，但字节原样保住（只读块 / 普通文本往返）；
- **重排** —— 认得出、语义不变，**首存会改字节**；
- **丢内容 / 增长** —— 首存丢字节，或每存一次还在长。

### 3.5 参考实现核过的几处（本轮新量的）

判不准的样本交给 CommonMark 官方参考实现（`commonmark@0.31.2` 的 `dist/commonmark.js`）。本轮量的是"上表里改法的判据对不对"，读数：

| 样本 | 规范读数 |
|---|---|
| `> Foo\nbar\n===` | blockquote / paragraph `"Foo\nbar\n==="` —— **三行一段**，`===` 是文字（下划线不能懒续） |
| `- Foo\nBar\n===` | list / item / paragraph `"Foo\nBar\n==="` —— 同上，列表那一侧也不能懒续 |
| `- Foo\n  bar\n  ===` | list / item / **heading(level=1)** `"Foo\nbar"` —— 缩进到内容列的续行**可以**参与 Setext（所以配对与否要看缩进，这一条我方仍是段落文字，见下） |
| `# Title\nFoo\n===` | heading + heading —— 上一行是块起始时，配对照旧（不许一刀切禁掉） |
| `> a\n\nbar\n===` | blockquote + heading `"bar"` —— 空行之后配对照旧 |
| `-     -      -      -` | **thematic_break** —— 一行整体是分割线时，列表项的解释让位（§4.1 例53） |
| ` ``` ```\naaa ` | paragraph：code `" "` ＋ softbreak ＋ text `"aaa"` —— 反引号围栏的信息串里不许有反引号，这一行不是围栏（§4.5 例108） |
| ` ``` aa ```\nfoo ` | paragraph：code `"aa"` ＋ softbreak ＋ text `"foo"`（§4.5 例115） |
| `~~~ aa ``` ~~~\nfoo\n~~~` | code_block(`"foo\n"`) info=`"aa ``` ~~~"` —— 波浪号围栏允许信息串含反引号（§4.5 例116） |
| `~~~ ~~~` | code_block info=`"~~~"` —— 是"开栏 ＋ 信息串"，**不是**同行开关 |
| `` `  ` `` | code `"  "` —— 全是空格的内容**不剥**空格（§6.1 例331） |
| `*foo\*\*bar*` | emph(`"foo**bar"`) —— 我方首存的写法在规范眼里仍是**一个**斜体（§6.2 例404） |
| `**foo\_\_bar\_\_baz**` | strong(`"foo__bar__baz"`) —— 同上 |

**一条**规范读数我方还没做到、这一轮也没动（不在本轮清单里）：`- Foo\n  bar\n  ===` 该是"项里一个跨行 Setext 标题"，我方是项内三行文字（字节全在，结构不对）。它与"懒续行的 `===` 不配对"是同一个判据的两侧：**配对要看文字行的缩进够不够到容器的内容列**，而这一轮只做了"上一行开着容器就不配对"这一半。

### 3.6 首存会改字节、但语义不变（重排类）

> **读数有两套账，别混**：本节下面的 72 / 230 是当时那一轮（GFM 裸自动链接之后）的逐条账，保留作历史；**2026-10-21 的普查读数是逐字节 224 / 首存即变 77 / 每轮都在变 1**（见 §0）。分类与例子仍然成立，数字以 §0 为准。

最常见的三种，都是"规范允许的等价写法被规范化"：

- **块之间补空行**：`Foo\n***\nbar` → `Foo\n\n***\n\nbar`；`# foo\n## foo` → 标题之间补空行；表格与相邻段落之间同理；`* Foo\n* * *\n* Bar` → 三块各补空行；
- **缩进被规范化**：`   ***` → `***`；` - - -` → `- - -`；围栏的开头缩进被去掉；空行里的多余空格被削；有序列表序号补空格对齐；
- **拼写被统一**：`_foo_` → `*foo*`；`*` 记号在某些组合里写成 `-`；`foo_bar_baz` → `foo\_bar\_baz`；`>a` → `> a`；`   > a` → `> a`；`Foo\` ＋换行＋`----`（Setext 内容行尾反斜杠）→ `Foo\\`；
- **围栏/代码段的等价改写**：` ``` aa ``` ` → `` ` aa ` ``、` ``` ``` ` → `` ` ` ``（同一个代码段，换一种围栏）。

**这一档比改前少 3 例（75 → 72），账要三条一起算**：

- **14 例升成"逐字节一致"**：例53、例61、例80 的两条、例102、例116、引用里的围栏代码块、引用里的缩进代码块、引用里的分割线、例281、任务项大写 `[X]`、有序任务项、例331、`~~~~foo~~~~`；
- **3 例从"逐字节一致"落进这一档**：`>a`、`   > a`（读法升级成引用块，记号被规范化）、Setext 内容行尾反斜杠（行内写手按规则把那个 `\` 写成 `\\`）—— 三条语义都没变、一轮后都稳定；
- **8 例从"每轮都在变"落到这里**：例108、例115、例404、例413、例631 等（上一节已逐条列出）。

净账：219 + 14 − 3 = **230**；75 − 14 + 3 + 8 = **72**；8 − 8 = **0**。
