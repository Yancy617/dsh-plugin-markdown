# 功能介绍

> ⚠️ **本文是插件自带的只读示例：改动不会被保存**，关掉再打开就回到原文。
> 想留自己的版本，请复制到你自己的目录里再改。

**这份文档本身就是演示**：下面列到的每一种写法都真的写在文件里，在当前这一页就能看到效果，也可以随手改。

## 一、块级写法

### 1. 标题 H1–H6

# 一级标题

## 二级标题

### 三级标题

#### 四级标题

##### 五级标题

###### 六级标题

斜杠菜单与命令面板里**六个级别都在**。

### 2. Setext 标题

文字行 ＋ 一整行 `=`（一级）或 `-`（二级）；下划线的长度按原样写回。

Setext 一级
===========

Setext 二级
-----------

标题内容里的行内格式也在：

Foo *bar*
=========

### 3. 段落与空段落

普通段落。段与段之间空一行。

连续的空行按**空段落**保真：下面是两个空段落，保存后一个字节都不少（口径：k 个连续空行 = k−1 个空段落，段间那个空行是分隔符不是空段落）。



所以上面那两个空行打开与保存都在。

### 4. 引用

> 引用会画一条竖线，可以跨多行。
> 第二行仍然在同一个引用块里。

引用里可以放多个段落、标题、列表、任务项、表格、代码块、分割线、图片与嵌套引用 —— 都按原样写回：

> 引用里的段落。
>
> #### 引用里的标题
>
> - 引用里的列表项
> - [x] 引用里的任务项（勾选状态与括号拼写都保留）
>
> | 甲 | 乙 |
> | --- | --- |
> | 1 | 2 |
>
> ```
> 引用里的围栏代码
> ```
>
> > 这是里层。

**惰性续行**：引用里的一行可以不写标记（下面第二行没有 `>`），保存后也不会给它补上：

> first
第二行是惰性续行。

### 5. 无序列表

记号 `-`、`*`、`+` 都认，**源里的记号原样写回**：

- 短横记号
- 第二个短横

换一种记号就是另一个列表：

* 星号记号
* 第二个星号

再加号：

+ 加号记号
+ 第二个加号

### 6. 有序列表

序号与分隔符（`.` 或 `)`）都按源写回，**不会重新编号**：

1. 第一步
2. 第二步
3. 第三步

全部写 `1.` 也不会被重新编号：

1. 全部写 1
1. 还是 1
1. 仍然 1

分隔符用 `)` 也可以：

1) 右括号一
2) 右括号二

起始序号与跳号都保留：

3. 从三开始
8. 跳到八

### 7. 任务列表

- [ ] 待办事项
- [x] 已完成的事项
- [X] 大写 X 也是勾选（括号的拼写原样写回）

### 8. 列表的嵌套与项内内容

嵌套两层、三层都按源写回（每级 2 格或 4 格都行，层数不限）：

- 第一层
    - 第二层（四格）
- 回到第一层

- 第一层
  - 第二层（两格）
- 回到第一层

- 第一层
  - 第二层
    - 第三层
      - 第四层

项里可以放标题与分割线：

- # 项里的标题
- Foo
- * * *

⚠️ 一项里多个段落、项里放代码块会丢形状 —— 见文末「已知限制」。

### 9. 代码块

三个以上的反引号或波浪号开栏（收尾不短于开栏）；信息串整串原样保留；**源里没有收尾行就不补**：

```js
// 反引号围栏
const a = 1
```

~~~~js
// 四个波浪号开栏，收尾也写四个
const b = 2
~~~~

~~~python
# 波浪号围栏，信息串整串保留
print("hello")
~~~

~~~
没有收尾行的围栏：一路读到文末，保存时也不会补一行
~~~

缩进四格（或一个制表符）是缩进代码块：

    四个空格开头的行是缩进代码块，
    它也原样保留。

代码块有**语法高亮**（用产品自己的着色器）。

### 10. 表格

外框可以省；对齐标记 `:--` 左、`:-:` 中、`--:` 右；单元格里可以用行内格式、链接与代码段；竖线写成 `\|`：

| 能力 | 状态 | 说明 |
| :-- | :-: | --: |
| 单元格内的**行内格式** | 可用 | 加粗、斜体、删除线、代码都能用 |
| 列对齐 | 可用 | 本表就是左 / 中 / 右 |
| 单元格里的竖线 | 可用 | 写成 \|，或者放进代码段里：`a|b` |
| 体比表头宽的行 | 可用 | 多出来的格子原样写回 |
| 体比表头窄的行 | 可用 | 缺的格子与空格子是同一件事 |
| **增删行列** | 可用 | 悬停一行或一列，外侧浮出手柄；点开菜单：上方 / 下方插入、删除（列是左侧 / 右侧 / 删除）。表头行不可删，至少留一行数据一列 |

**增删行列怎么用**：指针停在一个格子里，这一行左侧、这一列上方各出现一个小手柄。点手柄开菜单，
菜单里做不了的那一项是灰的，并在同一行写着原因（「表头不能删除」「至少要留一行」）。
插入 / 删除之后光标落在新格或接替那一格，撤销一步就回到操作前。

**改一格只改那一格**：`tablePatchedRaw` 按单元格 span 替换，分隔行、外框与其余格的字节都不动。

**结构编辑（增删行列）才会让整表按规范重写**：补上外框、分隔行写成
`---` / `:--` / `:-:` / `--:`、每格单空格。写出去的只有 GFM 能表达的东西，没有我们自己编的写法。

省略外框的写法（未改动时逐字节回放；**增删行列后整表会补上外框**）：

a | b
--- | ---
1 | 2

### 11. 分割线

三个以上同类字符，也允许写成 `- - -` / `* * *` / `_ _ _`：

---

- - -

***

_ _ _

*****

### 12. 链接定义与引用式链接

定义行是一个**不渲染的节点**（不占版面），三种引用形式都认：

[引用式链接][ref] · [折叠式][] · [简写式]

### 13. HTML 块

`<div>` 这类块按原文整块保留（不解析、不渲染，富文本里**只读**；源码视图也是只读的，所以目前这一类块没有修改入口，文件不会被损坏）：

<div>

这是一段 HTML 块，字节原样保住。

</div>

## 二、行内写法

### 14. 文字格式

**粗体** · *斜体* · ***粗斜体*** · ~~删除线~~ · `行内代码`

选中文字会浮出**格式工具栏**（`Ctrl/Cmd + B` 粗体、`Ctrl/Cmd + I` 斜体）。

行内代码里的反引号与反斜杠保得住：`` a`b ``、`` `C:\Users\me` ``

### 15. 链接

[行内链接](https://github.com/deepseek-ai/deepseek-harness) · [带标题的链接](https://example.com "标题也原样保留") · [目标里有空格](</my uri>)

**点一下就会打开网页**：先问 DSH 自己的浏览器标签（对话视图右栏那个）；那条路不通时（本面板是全局面板），**在这个面板的标签栏里新开一个「网页」标签，网页就显示在那一格里** —— 点标签栏里的文档标签就立刻回到文档，两种状态互斥。**拖动选中链接文字不会打开**（那是在选文字），**按住改键或中键点击也不接管**（留给浏览器）。载体起不来的站点（例如不允许被嵌入的页面）会在那一格里说明原因，并给一个「用系统浏览器打开」的按钮。

选中链接后工具栏会变成「编辑链接」，可以改地址或标题。

### 16. 自动链接

尖括号写法与 **GFM §6.9 的裸链接**都读成链接节点：

<https://example.com> · <foo@bar.example.com> · 裸链接 www.commonmark.org

裸 `www.` 会补上 `http://`、裸邮箱会补上 `mailto:`。裸 `http(s)://…` 与裸邮箱保存后写成尖括号形态（见「会被规范化的写法」）；裸 `ftp://` **不是**链接（GFM 只认 http/https）。**裸邮箱点了不打开**（点击判据只收 `http(s)`，与 `<foo@bar.baz>` 同一条规则）。

### 17. 图片

`![说明](地址)` 是**一个节点**：它会显示出来，删掉它是删掉整张图（不会剩下半个链接），保存时按你写的原样写回（`<>` 目标、单引号标题都照原样）。

![示例图片：深蓝底上的白色 Markdown Image 字样](.img/示例图片.jpg "标题也可以带：这是示例仓库自带的那张图")

**这一张是随插件一起装进来的**（`.img/示例图片.jpg`），所以在这份只读示例里能直接看到它。把它复制到你自己的目录时，**图也要一起复制过去**（否则那一格只会显示上面的说明文字）。

- **插入**：空行打 `/`，选「图片」——可以**选一个磁盘上的图片文件**（自动写进 `.img/` 并填好路径），也可以直接填一个已经在仓库里、或在网上的地址。**粘贴截图也可以**（`Ctrl+V`）。
- **放哪儿**：图片文件放在仓库根的 **`.img/`** 里（第一次插入时自动建）。文件树里不显示这个目录，磁盘上不隐藏——删不删是你的事。
- **路径怎么写**：相对**当前笔记**（`.img/x.png`；笔记在子目录里就写 `../.img/x.png`）。与 DSH 自己的预览同一套解析规则。`/` 开头会被当成操作系统绝对路径，别用。
- **文件名**：`20261009-221836-a1b2c3d4e5f6.png`——时间戳在前所以按名字排序就是按时间排序，后面那截是内容哈希，两台设备各粘各的也不会撞名。重名时**拒绝覆盖**，换一个名字再写。
- **远程图片**：`![](https://…)` 按标准直接渲染，所以打开含远程图片的笔记时浏览器会去取图。本插件自身不发其它网络请求。
- **加载顺序**：先出文字，图片在浏览器空闲时才取——三十张图的笔记和没有图的笔记一样快打开。
- **上限 20 MB**，与平台自己的文件路由同一个上限。
- **删图片节点不会删文件**：`.img/` 里的文件要你自己清。
- **`![alt](my file.png)` 不算图片**（规范如此，目标里有空格要写成 `<>`），按字面文字保留。
- **引用式写法的图片**字节正确，但模型是「引用」而不是图片节点，所以不显示成图（要显示成图请用上面那种直接写法）。

### 18. 转义

反斜杠只在**标点前**才是转义，这些写法按原样写回、不会变成结构：

\# 不是标题 · \- 不是列表 · \> 不是引用 · 1\. 不是有序列表 · \*不是强调\*

反斜杠本身也保得住：`C:\Users\me`、`a\b`

### 19. 字符引用

**命名实体**（`&amp;` `&copy;` `&hellip;`）原样写回、**不解码**（编辑器里看到的就是源码）：

AT&amp;T 与 &copy; 与 &hellip;

**数字字符引用**（十进制 `&#65;`、十六进制 `&#x41;`，含超范围的 `&#87654321;`）也一字不差，而且**可以在富文本里直接改**——它们落成普通段落，不再只读：

AT&amp;T 与 &#65; 与 &copy;

### 20. 行内 HTML

`<span>`、`<br/>` 这类行内标签按原文保留、不渲染：

<span>字面标签</span> 与 <br/> 与 <33> <\_\_>

### 21. 换行

行尾两个空格是硬换行，  
这一行是上一行的延续。

行尾一个反斜杠也是硬换行：\
这一行同样是延续。

段落里的单个换行是**软换行**，保存后照原样（不会合并成一行）：

第一行
第二行

## 三、编辑器与工作台

| 功能 | 在哪 | 说明 |
| --- | --- | --- |
| **多标签** | 顶部 | 每个标签独立保留未保存的改动 |
| **自动保存** | 不用点 | **停手 2 秒**自动落盘（手不停时最多 20 秒也存一次）；**粘贴后立刻**保存；**光标离开正文就立刻**保存（点侧栏、点标签栏、点查找框、点到面板外都算）；切文档、关标签、切到对话、窗口失焦同样**立刻**保存一次；`Ctrl/Cmd + S` 随时立刻保存（内容没变也会回一句「保存成功」）。成功**不弹提示**（`未保存` 标记消失就是反馈），失败才说话；**保存过程中界面照常可用**：能继续打字、切标签、拖动文件 |
| **另起一段** | `Ctrl/Cmd + Enter` | 在**光标所在的块之后**要一个可写的空段落 —— 表格、分割线、图片这些块里放不下光标，靠它出来（后面已经跟着空段落时，光标直接落在那一段上） |
| **文末总有一个空段落** | 打开文档时 | 文末是表格 / 分割线 / 图片的文档，最后一个孩子会被补成一个空段落，这样才有地方接着写。它**不写进文件**（文中你自己的空段落一个字节都不动） |
| **网页标签** | 顶部（点正文里的链接时出现） | 网页显示在这一格里；点文档标签立刻回文档，两种状态互斥 |
| **查找替换** | 工具栏放大镜 | 支持逐个替换与全部替换 |
| **文档目录** | 工具栏列表图标 | 点标题直接跳到对应位置 |
| **字数统计** | 文档标题旁 | 实时更新 |
| **富文本 / 源码** | 工具栏两个切换钮 | 源码视图只读，显示磁盘原文（带行号与总行数）；编辑在富文本里 |
| **重新载入** | 工具栏 | 丢弃编辑器改动，改读磁盘当前内容 |
| **文件树** | 左侧栏 | 新建文件 / 文件夹、重命名、删除（有二次确认）、复制路径、文件位置、刷新 |
| **拖动排序与移动** | 左侧栏的文件行 | 拖到别处换位置、拖到文件夹上（行的中间那一半）移进去，仓库内真的移动；顺序存在仓库根的 `.config/tree.json`，跟着仓库走。也可以从行的 `⋯` / 右键菜单 / 命令面板里挑「移动到…」 |
| **命令面板** | `Ctrl/Cmd + Shift + K` | 聚合全部工作台命令与块操作 |
| **斜杠菜单** | 空行输入 `/` | 正文、H1–H6、引用、三种列表、代码块、缩进 / 反缩进、分割线、表格、图片 |

### 状态不会丢

切到对话再切回来，**展开的目录层级、打开的标签、未保存的内容、滚动位置**都会恢复。

### 粘贴 Markdown

从 DSH 对话的复制按钮复制一条回答，直接粘贴进编辑器，**Markdown 会被解析成结构**——标题变成标题、表格变成表格、代码块变成代码块，而不是一堆字面字符。粘贴与"打开文档"走的是**同一条解析管道**：粘贴一段 Setext 标题、一段空段落、一个 `&#87654321;`，行为与打开一份文件一致。**从渲染过的代码块里复制是例外**：那时剪贴板带着 `<pre>` / `<code>`，它说的就是"这是代码" ⇒ 粘进来还是代码块。

## 四、保真承诺

**磁盘上的文件永远是干净的 Markdown。**

编辑器只接受能被 Markdown 无损表达的节点类型——没有对应语法的东西就不进 schema，而不是"先渲染、再序列化出别的东西"。

保真的证据是 `pnpm test` 里的探针：语料**导入再原样导出、逐字节比对**（会毁数据的那些会当场变红），纯函数规则门（图片地址、路径、空段落、转义拼写、保存稳定性），以及同一份文本反复"导出 → 重开"看第几轮开始变。写进源码视图看到的就是磁盘上的字节，两者是同一份。

文件开头的 **frontmatter**（`---` 围起来的那一段）只有整段像 YAML 键值结构（顶格每行是 `键: 值`、注释或空行；全空也算）时才被切走、保存时原样拼回；中间夹着正文、列表、表格的块按普通正文显示——不会再整段消失。被切走的 frontmatter 一个字都不会被改到，也因此不能在富文本里编辑。

## 五、会被规范化的写法（语义不变，一轮之后就稳定）

这些写法认得出、也写得回，只是**拼写会统一**一次 —— 下表每一条都逐字节量过：第一次保存改写，第二次起不变。

| 你写的 | 保存后 |
| --- | --- |
| `>a`、`   > a` | `> a`（标记后补空格、缩进归零） |
| ` - - -` | `- - -`（前导空格去掉） |
| `_foo_`、`__foo__` | `*foo*`、`**foo**`（下划线拼写不记在节点上） |
| `foo_bar_baz` | `foo\_bar\_baz`（词内下划线写成转义） |
| `[a](/url 'title')`、`[a](/url (title))` | `[a](/url "title")`（标题统一成双引号） |
| `[a](<>)` | `[a]()` |
| `## foo ##` | `## foo`（收尾井号去掉） |
| 裸 `https://…`、裸邮箱 | `<https://…>`、`<foo@bar.baz>` |
| `~~**x**~~` | `**~~x~~**`（标记按格式位写） |
| `<33> <__>` | `<33> <\_\_>`（字面下划线写成转义） |
| Setext 下划线上面那一行的行尾 `\` | `\\` |
| 文字行紧贴着标题 / 列表 / 表格 | 中间补一个空行 |
| 开头 `---` 紧贴着下一行文字（这一块不是 frontmatter） | 中间补一个空行 |
| 引用里「标题紧跟着列表」 | 中间补一条 `>` |

另外两条**一次性**的规范化：只有空白字符的"空行"会变成真空行（那几个空格存不下来）；列表旁边多出来的空行会少一个（松/紧保住了，那才是语义）。

## 六、已知限制

诚实列出，不藏。**下表这些都不会吞掉你的字**，但它们要么让那一段不能结构化编辑，要么会让形状或拼写变一次：

| 限制 | 说明 |
| --- | --- |
| **表格的行列** | 第一行永远是表头（不可删、也不能在它上方插行）；至少留一行数据与一列。合并单元格与"某行格子数比表头多"的表不支持增删行列（菜单里会说明原因）。列对齐用列手柄菜单的「对齐」组，只改分隔行那一格的字节。**改一格只改那一格**；**省略外框的表格**未改动时逐字节回放，只有增删行列才整表重排成带外框的写法（GFM 里两种写法等价） |
| **单元格里「粗体包着代码段」会掉格式** | 实测：单元格里写成「粗体 ＋ 行内代码段 ＋ 后面还有字」时（例如把 `.img/` 加粗后紧跟一句说明），保存后粗体标记失效并被转义成 `\*\*`。粗体在单元格**末尾**时正常，段落里也正常 —— 要加粗那一格请只写纯文字 |
| **一项里多个段落** | `- first` ＋空行＋ `  second` 会被写成 `- first` ＋换行＋ `  second`：那两个段落之间的空行没有单独的节点可放（内容不丢，松/紧会变） |
| **项里的代码块** | 列表项里的围栏代码块会丢围栏（实测只剩里头那一行文字）；要写代码块请别放进列表项 |
| **列表项里放不下引用** | `- a` 下面缩进写 `> b`，保存后那个引用会跑到列表**外面** |
| **列表项里的硬换行** | 段落里的行尾两个空格 / 行尾反斜杠都保得住，**列表项里那一个会被写成软换行** |
| **HTML 块只读** | `<div>` 之类的整块按原文保留，同上；本编辑器**不渲染** HTML |
| **开头像 frontmatter 但不是键值结构** | 按正文显示（不会藏起来）；反过来，文件一开头就是 `- a` 的独立序列、流式映射（`{a: b}`）和 `key:value`（冒号后没空格）也会被当成正文——真实 frontmatter 很少这么写 |
| **引用式图片不渲染成图** | 引用式写法走的是引用机制而不是图片节点，字节完全正确，只是不显示成图片 |
| **有些链接写法会规范化** | 见上一节（单引号 / 括号标题、`[a](<>)`、裸 `https://…`）。规范里认得出，只是字节会统一一次 |
| **文末那个换行不写回** | 保存后文件最后一行**不以换行结束**（其余未改动的地方逐字节写回）。这是编辑器与文件之间的一个固定差别 |
| **CRLF 文件** | 表格能正常解析，但行的 `\r` 会保留在文本节点里 |
| **切换标签会让网页重新加载** | 切走时那一格连同它的浏览器视图一起收掉，切回来重新加载（滚动位置与页面内状态不保留） |
| **网页标签只在桌面外壳上稳** | 桌面走官方那套 `<webview>`；Web 版退到沙箱 `iframe`，多数站点不允许被嵌入而显示不出来，会给「用系统浏览器打开」 |
| **无大文件保护** | 打开文件会把内容整个读进内存，没有大小上限 |
| **崩溃 / 被杀时最后一小段会丢** | 自动保存的丢失窗口是"停手 2 秒"（手不停时 20 秒）；被杀掉的进程不会把这段留下来（没有草稿兜底） |
| **图片要一次重启才生效** | 落盘那条路由在 Host 半边，Host 改动只在 DSH 下次启动时生效（装插件本来就要重启一次 DSH，见《关于》） |
| **界面只有中文** | 尚未接入 DSH 的本地化机制 |

## 七、这个插件不做什么

| 不做 | 理由 |
| --- | --- |
| 渲染 HTML / GFM 的 tagfilter | 载体只搬字节，不解析、不预览、不消毒；所以 GFM 6.11 那一类在一个"只写回 Markdown"的编辑器里不适用 |
| 高亮 `==text==` | 非标准扩展，会把正文里字面的 `==` 悄悄改写 |
| 下划线 | 规范里**没有**写法（`Ctrl+U` 与 HTML 粘贴里的 `<u>` 都会被摘掉），要加得先定写法 |
| Wiki 双链 / 反链 / 图谱 | 超出"常规 Markdown 编辑器"的范围 |
| 实时协作 / 评论 | 与"本地目录里的文件"这个模型根本冲突 |
| 移动端 | 编辑器加文件树在手机上是另一个产品 |
